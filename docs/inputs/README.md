# Raw material for the Definition-stage demo

This is what a real project actually has when somebody asks for a feature: a few
emails that disagree with each other, a conversation nobody wrote up properly, a
schema, and a one-line ask from the person paying.

The Session 1 demo turns this into a project brief and then a specification.

Nothing here is tidy on purpose. Two things are genuinely unresolved, and at least one
pair of statements flatly contradicts each other. A good agent surfaces both. A weak
one quietly picks a side.
